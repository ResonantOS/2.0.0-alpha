The only live-only dependency identified here is the configured recipient and
relay contract. **EMBED-UPSTREAM-1** must run before event-mapping implementation.
A matching recipient and protocol permit the specified mapping. Missing fields
or different shapes require a reviewed mapping update. A different product must
not receive shares under the Augmentor descriptor. This revision claims no live
result and introduces no DSH login or cookie assumptions.

Deferred minor extensions: a generic multi-harness state API and automatic
PID-reuse recovery. Their current behavior is explicit in the spec.
